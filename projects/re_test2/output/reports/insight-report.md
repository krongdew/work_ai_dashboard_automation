# Insight Questions

- ผลงานตีพิมพ์รวมของสถาบันมีแนวโน้มเพิ่มขึ้นหรือลดลงเมื่อเทียบระหว่างปีงบประมาณ?
- ภาควิชาใดมีผลงานการตีพิมพ์สูงสุด และภาควิชาใดต้องการการสนับสนุนเพิ่มเติม?
- ผลงานวิจัยส่วนใหญ่ได้รับการตีพิมพ์ในฐานข้อมูลระดับสากลประเภทใดมากที่สุด?
- สัดส่วนโครงการหรือผลงานที่บรรลุเป้าหมายเทียบกับที่ไม่บรรลุเป้าหมายเป็นอย่างไร?
