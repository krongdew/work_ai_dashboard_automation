# คู่มือการใช้งานระบบ Dashboard Factory

ระบบสร้างและจัดการ Dashboard จากไฟล์ Excel/CSV สำหรับคณะศิลปศาสตร์ มหาวิทยาลัยมหิดล
รองรับการใช้งานบนคอมพิวเตอร์และโทรศัพท์มือถือ

---

## 1. การเข้าสู่ระบบ (Login)

1. เปิดเว็บระบบ (เช่น `http://127.0.0.1:5050`)
2. กดปุ่ม **"เข้าสู่ระบบด้วย Google"**
3. เลือกบัญชี Google ของมหาวิทยาลัย (**ต้องเป็นอีเมล `@mahidol.ac.th` เท่านั้น**)

**เงื่อนไขการเข้าใช้งาน** — เข้าได้ก็ต่อเมื่อครบทั้ง 3 ข้อ:
- เป็นอีเมล `@mahidol.ac.th`
- อีเมลนั้นถูกเพิ่มเข้าระบบโดยผู้ดูแลระบบแล้ว (allowlist)
- บัญชียังเปิดใช้งานอยู่ (ไม่ถูกปิด)

หากขึ้นข้อความ *"อีเมลนี้ยังไม่ได้รับสิทธิ์เข้าใช้งาน"* ให้ติดต่อผู้ดูแลระบบเพื่อขอเพิ่มอีเมล

---

## 2. บทบาทผู้ใช้ (Roles)

| บทบาท | สิทธิ์ |
|---|---|
| **ผู้ดูแลระบบ (admin)** | เห็นทุกหน่วยงานและทุก dashboard, จัดการผู้ใช้/หน่วยงาน/หน่วยย่อยได้ |
| **สมาชิก (member)** | เห็นเฉพาะข้อมูลและ dashboard ของ **หน่วยงานตัวเอง** เท่านั้น |

ผู้ดูแลระบบหลักคนแรกคือ `krongkwan.bua@mahidol.ac.th`

---

## 3. การจัดการผู้ใช้และหน่วยงาน (เฉพาะผู้ดูแลระบบ)

เมนู **"จัดการระบบ (Admin)"**

### 3.1 หน่วยงานและหน่วยย่อย
- สร้างหน่วยงาน เช่น "คณะศิลปศาสตร์"
- เพิ่มหน่วยย่อยในแต่ละหน่วยงาน เช่น "งานบริการการศึกษา", "งานวิจัย"

### 3.2 ผู้ใช้
- **เพิ่มผู้ใช้**: กรอกอีเมล `@mahidol.ac.th` + ชื่อ + บทบาท (admin/member)
- **กำหนดหน่วยงาน**: เลือกหน่วยงาน (และหน่วยย่อย) ให้ผู้ใช้แต่ละคน — ผู้ใช้จะเห็นเฉพาะ dashboard ของหน่วยงานที่กำหนด
- **ปิดการใช้งาน**: ปิดบัญชีผู้ใช้ที่ไม่ต้องการให้เข้าระบบ (ลบผู้ดูแลหลักไม่ได้)

> ผู้ใช้ใหม่ต้องถูกเพิ่มที่นี่ก่อน จึงจะ login ด้วย Google ได้

---

## 4. การสร้าง Dashboard (ทีละขั้นตอน)

ระบบนำทางเป็นขั้นตอน:

1. **สร้าง/เลือกโปรเจกต์** — ตั้งชื่อโปรเจกต์ (เช่น `student-2567`). โปรเจกต์ที่สร้างจะผูกกับหน่วยงานของคุณอัตโนมัติ
2. **อัปโหลดข้อมูล** — เลือกไฟล์ `.xlsx` / `.csv` ใส่เข้าโปรเจกต์
3. **Profile ข้อมูล** — ระบบวิเคราะห์โครงสร้างข้อมูล (คอลัมน์ ชนิด วันที่ ตัววัด) โดยไม่แก้ไฟล์ต้นฉบับ
4. **ตั้งกฎการคำนวณ** (ถ้าต้องการ) — ปีการศึกษา, รูปแบบรหัสนักศึกษา, เกณฑ์ความเสี่ยง GPAX ฯลฯ
5. **ให้ AI เสนอ/ปรับ Spec** — AI (Local AI หรือ Groq) เสนอ KPI และกราฟ โดยส่งเฉพาะ metadata ที่ลดข้อมูลแล้ว ไม่ส่งข้อมูลดิบออกนอกเครื่อง
6. **สร้าง Dashboard** — ระบบคำนวณจากข้อมูลจริงและสร้างหน้า dashboard พร้อมผล QA
7. **เปิดดู / ดาวน์โหลด** — เปิด dashboard หรือดาวน์โหลดเป็นแพ็กเกจ

**มุมบนขวา** แสดงว่าตอนนี้ระบบใช้ AI ตัวไหน (Local AI / Groq Cloud / LAN Worker)

---

## 5. การลบโปรเจกต์หรือ Dashboard

- ในรายการ dashboard กดปุ่ม **ลบ** ที่การ์ดของโปรเจกต์
- ระบบจะถามยืนยันก่อนลบ (ลบแล้วกู้คืนไม่ได้)
- สมาชิกลบได้เฉพาะโปรเจกต์ของหน่วยงานตัวเอง; ผู้ดูแลระบบลบได้ทุกอัน

---

## 6. การใช้งานบนมือถือ

หน้าจอปรับขนาดอัตโนมัติ (responsive) — ใช้งานได้บนมือถือและแท็บเล็ต เมนูจะยุบเป็นแบบแตะเปิด

---

## 7. ความปลอดภัยของข้อมูล

- ไฟล์ต้นฉบับในโฟลเดอร์ `input/` จะไม่ถูกแก้ไข
- ไม่ส่งข้อมูลดิบ รหัสประจำตัว หรือข้อมูลส่วนบุคคลออกไปยัง AI บนคลาวด์ — ส่งเฉพาะ metadata ที่ลดข้อมูลแล้ว
- การคำนวณ KPI และการสร้าง dashboard ทำในเครื่องทั้งหมด
- ปีที่แสดงบน dashboard เป็น พ.ศ. เสมอ

---

## 8. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| login ไม่ได้ ("ยังไม่ได้รับสิทธิ์") | ให้ผู้ดูแลเพิ่มอีเมลของคุณในเมนูจัดการผู้ใช้ |
| ไม่เห็น dashboard ของเพื่อนร่วมงาน | คุณเห็นเฉพาะหน่วยงานตัวเอง — ให้ผู้ดูแลตรวจว่าอยู่หน่วยงานเดียวกัน |
| มุมบนขวาขึ้น "Groq Cloud" แต่อยากใช้ในเครื่อง | แก้ `.env` เป็น `AI_PROVIDER=local` แล้ว restart ระบบ |
| AI ไม่ทำงาน (local) | เปิด LM Studio server ที่พอร์ต 1234 ก่อน |
